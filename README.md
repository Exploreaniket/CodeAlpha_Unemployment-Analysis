# 📊 Unemployment Analysis with Python

> An end-to-end data analysis project exploring unemployment trends, regional variations, urban-rural differences, employment relationships, and changes during the COVID-19 period in India using Python.

---

## 📌 About the Project

Unemployment is an important economic indicator that can vary across regions and time periods.

This project performs an end-to-end exploratory data analysis of unemployment data in India covering the period from **May 2019 to June 2020**.

The project analyzes unemployment rates, estimated employment, labour participation, regional differences, urban-rural patterns, monthly trends, and changes during the COVID-19 period.

The goal of this project is to demonstrate a complete **Data Analyst / Data Science workflow using Python**, starting from raw data and ending with meaningful insights and visualizations.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze unemployment trends over time.
- Identify periods with high and low unemployment.
- Compare unemployment across different regions of India.
- Analyze urban and rural unemployment patterns.
- Study the relationship between unemployment and employment.
- Analyze labour participation rates.
- Compare unemployment before and during the COVID-19 period.
- Analyze regional differences during the COVID period.
- Study monthly unemployment patterns.
- Identify potential outliers.
- Create meaningful data visualizations.
- Extract data-driven insights.
- Demonstrate an end-to-end Python data analysis workflow.

## 🗂️ Dataset

The dataset contains unemployment-related information for different regions of India.

### Dataset Information

| Attribute | Details |
|---|---|
| Country | India |
| Time Period | May 2019 – June 2020 |
| Total Records | 740 |
| Total Columns | 10 |
| Missing Values After Cleaning | 0 |
| Duplicate Records After Cleaning | 0 |
| Data Type | Structured / Tabular |

### Dataset Features

| Column | Description |
|---|---|
| `Region` | Region/State of India |
| `Date` | Date of observation |
| `Frequency` | Frequency of data collection |
| `Estimated Unemployment Rate (%)` | Estimated unemployment rate |
| `Estimated Employed` | Estimated number of employed people |
| `Estimated Labour Participation Rate (%)` | Estimated labour participation rate |
| `Area` | Urban or Rural |
| `Year` | Extracted year from the date |
| `Month` | Extracted month number |
| `Month_Name` | Extracted month name |
